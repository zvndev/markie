# Office fixtures

`markie-fixture-hand.ttf` is the font the embedded-font tests put inside a Word
file (`../docx-fonts.test.ts`). It is a modified copy of Caveat (the regular
weight, cut down to the ASCII letters and renamed "Markie Fixture Hand"), from
https://github.com/google/fonts/tree/06bfe0d62a98375cb09c942fa18e68bd32cff057/ofl/caveat.
Caveat is under the SIL Open Font License 1.1, and so is this copy: the license
is in `markie-fixture-hand.LICENSE.txt`. It is a test fixture only and is not
shipped in any build.
