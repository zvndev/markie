# Media and web links

Put a picture of your own beside this file as `scene.png`, and a short video as `clip.mp4`. Neither is tracked in the repository.

Double-click this picture in the editable rich view. Click outside it to close.

![Synthetic landscape](scene.png)

Use the video's own controls, or Expand for the larger viewer.

![Synthetic local clip](clip.mp4)

Rest on [Example Domain](https://example.com/) for a safe public metadata preview. Clicking it should open your device's default browser, not a Markie web window.

These samples are local and disposable. Viewing media or links should not change this source.
